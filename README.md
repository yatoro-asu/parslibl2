# Библиотека книг

Проект собирает книги с [knigofil.org](https://knigofil.org/), сохраняет метаданные в JSON и генерирует статический сайт с карточками книг.

## Возможности

- карточки с обложкой, названием, автором и жанрами;
- ссылки на тексты книг в новой вкладке;
- пагинация: по 10 книг на странице;
- локальные CSS и изображения для работы без CDN;
- автоматическая пересборка страницы через live reload.

## Установка

Требуется Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
```

## Сбор данных

```bash
python main.py
```

По завершении появятся `books.json`, папка `images11/` с обложками и папка `books/` с текстами.

## Генерация сайта

```bash
python generate_site.py
```

Команда создаёт [index.html](index.html) и страницы `index-2.html` и далее. Шаблон находится в `templates/books_template.html`, данные берутся из `books.json`.

## Локальная проверка

Для проверки без внешних ресурсов запустите простой сервер из корня проекта:

```bash
python -m http.server 8000
```

Откройте `http://127.0.0.1:8000/index.html`.

Для автоматической пересборки при изменении JSON или шаблона:

```bash
python serve.py
```

## Структура

| Путь | Назначение |
|---|---|
| `main.py` | сбор книг и файлов |
| `books.json` | данные книг |
| `generate_site.py` | генерация HTML |
| `templates/` | шаблон Jinja2 |
| `static/css/` | локальный Bootstrap CSS |
| `static/images/` | локальные обложки |
| `index.html` | первая страница сайта |
# Парсер книг

Скрипт собирает книги из раздела боевой фантастики на сайте [knigofil.org](https://knigofil.org/fighting-fantasy/), получает их описание, ссылки на обложки и тексты, а затем скачивает доступные файлы.

## Возможности

- сбор ссылок с заданного диапазона страниц фантастики;
- получение названия, автора, жанров и года издания;
- проверка ссылок на обложку и текст;
- сохранение сведений о книгах в `books.json`;
- скачивание обложек в `images11/` и текстов в `books/`;
- обработка сетевых ошибок с повторными попытками;
- выбор типа скачиваемых файлов через аргументы командной строки.

## Установка

Требуется Python 3.10 или новее.

```bash
pip install requests beautifulsoup4 sanitize-filename
```

## Запуск

По умолчанию обрабатываются страницы с 1 по 10:

```bash
python main.py
```

Можно указать начальную и конечную страницы:

```bash
python main.py 1 10
```

Пропустить скачивание обложек или текстов:

```bash
python main.py 1 10 --skip_imgs
python main.py 1 10 --skip_txt
```

Доступна также форма с дефисами: `--skip-imgs` и `--skip-txt`.

## Результаты

| Путь | Содержимое |
|---|---|
| `books.json` | Метаданные, URL и локальные пути файлов |
| `images11/` | Скачанные обложки |
| `books/` | Скачанные тексты книг в формате `.txt` |

Пример записи в `books.json`:

```json
{
	"title": "Дракон (СИ)",
	"author": "Юлия Чернявская",
	"genre": "Боевая фантастика",
	"release": "2018",
	"url": "https://knigofil.org/fighting-fantasy/18161-drakon.html",
	"image_url": "https://knigofil.org/uploads/posts/...jpg",
	"text_url": "https://knigofil.org/uploads/book/...txt",
	"img_src": "images11/cover.jpg",
	"book_path": "books/Дракон (СИ).txt"
}
```

Если файл не был скачан из-за флага `--skip_imgs`, `--skip_txt` или отсутствующей ссылки, соответствующий локальный путь в JSON не добавляется.
